# HARNESS-FACTS — what the kit knows about the harnesses it runs on

The kit installs to Claude Code, Codex, Gemini CLI, ZCode, OpenCode,
omp, Kilo and Droid. What it has learned about each is scattered
through decision records, tests, and eval results; this page is the
one place a contributor reads before relying on a harness behaviour.
It routes — the named evidence arbitrates.

## Adding a row

A fact enters only with its evidence, named in the row: a test that
pins the behaviour, a decision record, or a recorded eval result —
and only for what this repository itself establishes, never copied
from another project (its host is not this one). An assumption is
behaviour the kit leans on that nothing here pins; it leaves the
table only when a test or a recorded run establishes it, and until
then its row says how to verify it. When a verification lands, the
row moves to the facts table with its new evidence.
