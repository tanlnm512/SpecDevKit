# D-007 — One panelist archetype, lens payloads

- **Context**: three lens briefs (visionary, cynic, minimalist), each
  a near-identical seat contract (full conviction, digest only, no
  writes) wrapped around one lens's method. The seat contract is the
  archetype; only the lens content differs — and independence (D-002)
  comes from fresh parallel spawns, not from the file count.
- **Decision**: `agents/panelist.md` is the one archetype (the seat
  spine: one lens at full conviction, grounded in the payload, digest
  only); `agents/_lenses.md` carries the three lens sections
  (mission, method, rubric, digest fields) injected verbatim into
  each spawn by the session per the payload contract in
  `contracts/run.md`. The three per-lens brief files are deleted.
  Stage shapes, the digest grammar, the matrix, and the handoff gate
  are unchanged.
- **Consequences**: brief surface 3→1 + the data table; def installs
  drop two files per dialect; a fourth lens (e.g. an operator lens)
  becomes one table section. The panel protocol
  (`_panel-protocol.md`) is unchanged and still prepended to every
  spawn. Serves eval cases B1–B3: panel independence is the spawn
  mechanics, which did not move.
