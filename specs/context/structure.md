# Code structure — SpecDevKit

**Baseline**: bc5e9de + current working tree (2026-09-22 assurance hardening) · living view — later specs' surveys
read this first and re-survey only the delta.

## Module map

- `skills/spec-to-prod/` — the skill itself (the product):
  - `SKILL.md` — the orchestrator playbook (workflow graph, spawn
    mechanics, run modes, execution mode, harness sections).
  - `agents/spec-*.md` — the eight role briefs + `_shared-protocol.md`
    (shared agent rules); frontmatter + body in one file, installed as
    agent defs where a harness reads them.
  - `scripts/` — the mechanical core, stdlib-only: `graph.py` (the
    workflow engine: state oracle, `--emit-spawns`, `--run`),
    `check.py` (verify-node checks), `audit.py` (closing-audit helpers:
    scope/clean/proofs/dod/converge), `specstate.py` (shared doc-state
    parsers), `tick.py` (task ticker), `scaffold.sh`, `archive.sh`,
    `skill-dir.sh`.
  - `scripts/freeze.py` — post-approval hash manifest and integrity
    verification; `scripts/specstate.py` also exposes lifecycle SHA values
    and conservative task-touch overlap.
  - `templates/` — the seven doc templates plus constitution,
    closing-evidence, release-handoff, and post-delivery templates.
  - `commands/` — the router + six lifecycle commands (+ `extra.txt`).
  - `workflows/` — generated dynamic-workflow dialects
    (regenerate-only; see tools/workflow-defs.py).
  - `decisions/` — ADRs 001–021; `contracts/docset.md` — the file
    ownership/status contract; `gates/`, `references/`, `evals/`,
    `tests/` (the scripts' own suites), `VERSION`, `CHANGELOG.md`.
- `tools/` — repo install/maintenance tooling: `sync.sh` (the one
  installer: skills/commands/defs/workflows per root + verify),
  `omp-defs.py` / `agent-defs.py` (agent-def dialect generators),
  `workflow-defs.py` (workflow dialect generator),
  `install-workflow.sh` (per-harness workflow installer),
  `plugin-manifest.py` (marketplace manifests), `tests/` (tooling
  suites, fake-HOME convention).
- `agents/` (repo root) — committed regenerate-only Antigravity
  personas; byte-equal to the skill briefs (verified every sync).
- `specs/` — this repo's own specs (INDEX.md, CONSTITUTION.md,
  context/, per-spec dirs).
- `.claude-plugin/marketplace.json` + root `plugin.json` — plugin
  packaging (regenerated by tools/plugin-manifest.py).

## Entry points

- Orchestrator surface: `/spec-to-prod <verb> <name>` router and the six
  lifecycle commands (`/spec`…`/ship`); omp `/skill:spec-to-prod`.
- Native workflow surface: `/spec-run` (zcode `.dwf.ts`, claude `.js`)
  — the frontier loop driven by graph.py's oracle.
- Install: `tools/sync.sh` (everything), `tools/install-workflow.sh`
  (workflows only, per harness).

## Ownership

- Everything under `skills/spec-to-prod/` is the skill's product
  surface; `tools/` is repo tooling; generated artifacts
  (`skills/*/workflows/`, root `agents/`, manifests) are regenerate-only
  — never hand-edited.
